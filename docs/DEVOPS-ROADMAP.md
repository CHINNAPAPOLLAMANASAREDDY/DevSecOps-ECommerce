# DevOps Roadmap for DevShop

## Phase 1 - Application
- Spring Boot REST API
- MySQL persistence
- Existing HTML/CSS/JS frontend

## Phase 2 - API Testing
- Postman collection
- Health, product and order APIs

## Phase 3 - Containers
- Multi-stage Docker build
- Docker Compose for Spring Boot + MySQL

## Phase 4 - Security
- Trivy filesystem scan
- Trivy Docker image scan
- SonarQube configuration

## Phase 5 - CI/CD
- GitHub Actions
- Maven tests
- Docker build
- Optional Docker Hub publishing

## Phase 6 - Kubernetes
- Deployment
- Service
- MySQL deployment
- Persistent volume
- ConfigMap
- Secret
- 2 application replicas
- Readiness and liveness probes
